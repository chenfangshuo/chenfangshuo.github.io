# forsure.live

个人博客，随手记录一些折腾过程 —— 线上地址 [forsure.live](https://forsure.live)。

用 [Hugo](https://gohugo.io/) 配合 [FixIt](https://fixit.lruihao.cn/) 主题构建，文章是普通的 Markdown，源码就放在这个仓库里；向 `main` 推送后由 GitHub Actions 自动构建并发布到 GitHub Pages。评论使用自建的 [Twikoo](https://twikoo.js.org/)，站内搜索是构建期生成的本地索引。
